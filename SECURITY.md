# Security

This alpha authentication package remains disabled until operator-controlled public
checks and a real candidate login pass. Requirements gaps are recorded explicitly.
Use GitHub private vulnerability reporting for this repository. Do not submit keys,
tokens, callback queries or personal claim data. Aim: acknowledge within five working
days; no alpha remediation SLA is promised. Critical/high dependency vulnerabilities
block release. Maintain Umbraco and .NET security updates independently.

CI runs native compilation, xUnit tests, real host/container smoke checks, dependency
audits and CodeQL for C#/Actions. Dependabot checks weekly. Signed release provenance,
SBOM, broader platform/browser/conformance coverage and independent review are planned.
